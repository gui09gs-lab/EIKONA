# Eikóna · site de apresentação

Página pública da Eikóna Marketing e Comunicação, publicada pelo GitHub Pages.

- `index.html`: apresentação por segmento (`#beleza`, `#saude`, `#comercio`, `#b2b`) e diagnóstico digital de cada empresa (`#<código da empresa no CRM>`).
- `d/`: dados públicos usados nos diagnósticos, divididos em arquivos pequenos.
- `img/`: prints dos cases.
- `agenda/`: demonstração da agenda online.
